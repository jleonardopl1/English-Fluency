# Assessment & Rubrics (the `/test` flow)

Use to place a new learner or re-measure progress (every ~2–4 weeks). Keep it low-pressure — "a check-in, not a grade." Output a CEFR estimate per skill, named strengths, named gaps, and an updated focus list. Save results to the progress file so trends are visible.

## How to run a placement/progress test (~10 min)

Mix tasks across skills. Adapt difficulty live (start mid, climb or back off). Use one task at a time.

1. **Spoken-style fluency** (typed): give a topic at the suspected level; have them respond in several sentences. Assess fluency, range, error density. (Topics in `onboarding.md` and `activities-library.md`.)
2. **Grammar production:** 3–5 transform/fill-in items targeting key structures for the level (present perfect, conditionals, articles, prepositions).
3. **Vocabulary range:** ask them to describe something needing varied words; or a quick synonym/collocation task.
4. **Naturalness:** give a correct-but-clunky sentence; ask them to make it sound natural (reveals B2+ ability).
5. **Pronunciation self-report (optional):** ask them to record a sentence and tell you what felt hard; or assess from their phonetic descriptions.

## Scoring rubric (per skill, 1–5 → mapped to CEFR)

Score each dimension 1–5, then map to a CEFR band.

| Dimension | What you're judging |
|---|---|
| **Fluency** | Length, flow, hesitation, ability to sustain a topic |
| **Accuracy** | Grammar correctness; error density and severity |
| **Range** | Vocabulary breadth, grammatical variety |
| **Naturalness** | Collocations, idioms, phrasing, rhythm — how "American" it sounds |
| **Comprehension** | (when relevant) understanding your questions/texts |

**Rough mapping (average across dimensions):**
- 1.0–1.5 → A1 · 1.5–2.2 → A2 · 2.2–3.0 → B1 · 3.0–3.8 → B2 · 3.8–4.5 → C1 · 4.5–5.0 → C2

Track skills separately — a learner is often uneven (e.g. B2 vocab, A2 pronunciation). Record each.

## CEFR quick descriptors (for judging)

- **A1:** words/short phrases; frequent basic errors; can't sustain.
- **A2:** simple sentences; present-heavy; agreement/tense errors; short answers.
- **B1:** connects ideas; past/future handled; noticeable but non-blocking errors; holds a basic conversation.
- **B2:** fluent on familiar topics; good range; errors in nuance/prepositions/articles; argues a point.
- **C1:** flexible, precise, near-natural; subtle errors only; abstract topics fine.
- **C2:** near-native; idiomatic; rare minor errors.

## Output format for a test

```
## 📊 Level Check — [date]

**Overall: [CEFR]** (was [previous] on [date]) [↑/→]

| Skill | Level | Note |
|---|---|---|
| Speaking/Fluency | B1 | Sustains topics; hesitates on past tense |
| Grammar/Accuracy | A2+ | 3rd-person -s and present perfect are the gaps |
| Vocabulary/Range | B1 | Good everyday range; few phrasal verbs |
| Naturalness | A2 | Phrasing still translated from PT |
| Pronunciation | A2 | TH and final-vowel epenthesis |

**Strengths:** [2–3 specific things]
**Top 3 to work on next:** [pattern], [pattern], [pattern]
**Recommended focus this cycle:** [one main thing]
```

Then warmly recommend next steps (a drill on the #1 gap, a plan, etc.). Always point out improvement vs the last test if there is any — it's the best motivator.

## Goal-specific assessment notes
- **Exam prep (TOEFL/IELTS/Cambridge):** assess against that exam's bands and task types; mimic its formats in drills.
- **Work English:** test on meeting/email/presentation tasks specifically.
- **"Sound native":** weight Naturalness and Pronunciation heavily; these are the true frontier above B2.
